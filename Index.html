📋 Faculty Evaluation System · full details

Palompon Institute of Technology – Tabango Campus | aligned with CHED CMO No. 19, s. 2025

🎯 problem

Manual paper‑based evaluations caused delays, clerical errors, and difficulty in aggregating feedback for teaching, research, and service. Data redundancy and lack of real‑time reports hindered decision‑making.

💡 solution

Automated online platform with role‑based access (student, peer, supervisor). Real‑time dashboards, automated computation of weighted means, and encrypted data storage ensure reliability and compliance with CHED standards.

📐 methodology

Rapid Application Development (RAD) System Prototype Model – iterative prototyping with continuous user feedback from administrators, faculty, and students.

⭐ key features (from document)

  • Student, peer & supervisor evaluation forms
  • Automated scheduling & evaluation periods
  • RBAC (admin, dean, faculty, student)
  • Weighted mean computation & analytics
  • PDF report generation (individual & department)
  • Supervisor Evaluation for Faculty (SEF)
  • Anonymous submission & audit log
  • Responsive web – desktop, tablet, mobile

🛠️ tech stack

PHP · MySQL · JavaScript · Bootstrap · XAMPP · Chart.js

impact: reduced processing time, 80% fewer manual errors, CHED-aligned documentation.
