Rhyzil Tech Website
A modern and responsive company website for Rhyzil Tech built using HTML, CSS, and Vanilla JavaScript. The project features a clean UI, smooth animations, responsive layouts, dark and light theme support, portfolio showcases, pricing sections, interactive service tabs, and an AI chatbot interface.
